# Environment reference

`.env.example` is the local template. Production and staging values live **only** on the server in
`/var/www/htfarms/shared/.env` (mode 640, owner `deploy:www-data`). They are never stored in Git, in build
artifacts or in GitHub.

## Application variables

| Variable | Production value / example | Notes |
|---|---|---|
| `APP_NAME` | `"H & T Integrated Farms"` | |
| `APP_ENV` | `production` (`staging` on staging) | Development accounts are seeded only when not `production`. |
| `APP_KEY` | `base64:…` | Generate **once per environment** (`php artisan key:generate --show`) and keep it. Changing it logs everyone out and makes encrypted data unreadable. The deploy script refuses to run without it. |
| `APP_DEBUG` | `false` | The deploy script refuses to deploy if it is not `false`. |
| `APP_URL` | `https://htintegratedfarms.com` | Used for signed draft links, emails and absolute links (media URLs are root-relative). Must match the public URL exactly. |
| `APP_TIMEZONE` | `Africa/Lagos` | |
| `TRUSTED_PROXIES` | empty, or Cloudflare IP ranges | Set only if traffic passes through a proxy/CDN, so rate limiting sees real client IPs. |
| `LOG_CHANNEL` / `LOG_STACK` | `stack` / `daily` | |
| `LOG_LEVEL` | `warning` | |
| `LOG_DAILY_DAYS` | `14` | |
| `DB_CONNECTION` | `mysql` | |
| `DB_HOST` / `DB_PORT` | `127.0.0.1` / `3306` | |
| `DB_DATABASE` / `DB_USERNAME` / `DB_PASSWORD` | `htfarms` / `htfarms` / *secret* | Per-environment database and user. |
| `SESSION_DRIVER` | `database` | |
| `SESSION_SECURE_COOKIE` | `true` | |
| `CACHE_STORE` | `redis` | |
| `CACHE_PREFIX` | `htfarms_prod_` | Must differ between environments that share one Redis server. |
| `QUEUE_CONNECTION` | `redis` | Workers run under Supervisor. |
| `REDIS_CLIENT` / `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD` | `phpredis` / `127.0.0.1` / `6379` / *optional* | |
| `MEDIA_DISK` | `public` | Uploaded images live in `shared/storage/app/public`. |
| `QUEUE_CONVERSIONS_BY_DEFAULT` | `true` | Image sizes are generated by the queue worker. |
| `MAIL_MAILER` | `smtp` | |
| `MAIL_HOST` / `MAIL_PORT` / `MAIL_USERNAME` / `MAIL_PASSWORD` / `MAIL_SCHEME` | provider values | Any SMTP provider (e.g. Postmark, Mailgun, SES SMTP, Zoho). |
| `MAIL_FROM_ADDRESS` / `MAIL_FROM_NAME` | `no-reply@htintegratedfarms.com` / `"H & T Integrated Farms"` | The domain needs SPF/DKIM for the provider. |
| `ENQUIRY_NOTIFICATION_EMAIL` | `sales@…` | Fallback recipients for new-enquiry alerts. **Admin → Site settings** overrides it. |
| `ENQUIRY_VERIFY_EMAIL_DNS` | `true` | MX/A lookup on submitted addresses. Tests and CI set it to `false`. |
| `ENQUIRY_RATE_LIMIT` / `ENQUIRY_RATE_LIMIT_DECAY` | `5` / `600` | Submissions per IP per form per window (seconds). |
| `ENQUIRY_MIN_FILL_SECONDS` | `3` | Submissions faster than this are treated as bots. |
| `ENQUIRY_CAPTCHA` | `none` or `turnstile` | |
| `TURNSTILE_SITE_KEY` / `TURNSTILE_SECRET_KEY` | from Cloudflare | Both are required when `ENQUIRY_CAPTCHA=turnstile`; otherwise the app falls back to no captcha. The site key is public; the secret key is not. |
| `TURNSTILE_TIMEOUT` | `5` | Seconds. If Cloudflare is unreachable the app fails open and logs a warning. |
| `QUOTE_DRAFT_LIFETIME_DAYS` | `14` | |
| `ANALYTICS_PROVIDER` | `none`, `plausible` or `ga4` | Loaded only after the visitor consents to analytics. |
| `ANALYTICS_ID` | domain (Plausible) or `G-…` (GA4) | |
| `ANALYTICS_SCRIPT_SRC` | optional | For a self-hosted Plausible script. |

### Production `.env` skeleton

```dotenv
APP_NAME="H & T Integrated Farms"
APP_ENV=production
APP_KEY=                      # php artisan key:generate --show
APP_DEBUG=false
APP_URL=https://htintegratedfarms.com
APP_TIMEZONE=Africa/Lagos
LOG_CHANNEL=stack
LOG_STACK=daily
LOG_LEVEL=warning
LOG_DAILY_DAYS=14
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=htfarms
DB_USERNAME=htfarms
DB_PASSWORD=
SESSION_DRIVER=database
SESSION_SECURE_COOKIE=true
CACHE_STORE=redis
CACHE_PREFIX=htfarms_prod_
QUEUE_CONNECTION=redis
REDIS_CLIENT=phpredis
REDIS_HOST=127.0.0.1
MEDIA_DISK=public
QUEUE_CONVERSIONS_BY_DEFAULT=true
MAIL_MAILER=smtp
MAIL_HOST=
MAIL_PORT=587
MAIL_USERNAME=
MAIL_PASSWORD=
MAIL_FROM_ADDRESS=no-reply@htintegratedfarms.com
MAIL_FROM_NAME="${APP_NAME}"
ENQUIRY_NOTIFICATION_EMAIL=
ENQUIRY_VERIFY_EMAIL_DNS=true
ENQUIRY_CAPTCHA=turnstile
TURNSTILE_SITE_KEY=
TURNSTILE_SECRET_KEY=
ANALYTICS_PROVIDER=none
ANALYTICS_ID=
```

## GitHub configuration

Create two **Environments** (Settings → Environments): `staging` and `production`. For `production`, add
required reviewers and restrict deployments to the `main` branch; restrict `staging` to the `staging` branch.

### Environment variables (`vars`)

| Name | Example | Purpose |
|---|---|---|
| `DEPLOY_HOST` | `203.0.113.10` | VPS hostname or IP |
| `DEPLOY_PORT` | `22` | SSH port (default 22) |
| `DEPLOY_USER` | `deploy` | Dedicated deploy user (default `deploy`) |
| `DEPLOY_PATH` | `/var/www/htfarms` | Base path (default `/var/www/htfarms`; e.g. `/var/www/htfarms-staging` for staging) |
| `APP_URL` | `https://htintegratedfarms.com` | Used for the post-deploy health check and the environment link |
| `DEPLOY_KNOWN_HOSTS` | output of `ssh-keyscan -t ed25519 -p 22 <host>` | **Verify the fingerprint out of band** (compare with `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` on the server). Deploys refuse to run without it. |

### Environment secrets (`secrets`)

| Name | Purpose |
|---|---|
| `DEPLOY_SSH_KEY` | Private key (ed25519) whose public key is in `/home/deploy/.ssh/authorized_keys`. Generate one key per environment; it must not be used for anything else. |

No application secrets (database, mail, Turnstile, `APP_KEY`) are stored in GitHub.
